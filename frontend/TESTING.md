# ZenHome 微信小程序测试指南

## 前置准备

### 1. 确保后端运行

```bash
cd backend
npm run dev
```

后端应该运行在 `http://localhost:3000`

### 2. 启动前端

```bash
cd frontend
npm run dev:weapp
```

### 3. 打开微信开发者工具

- 导入项目，选择 `frontend` 目录
- AppID 使用测试号
- **重要**：勾选 "不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书"

## 功能测试清单

### ✅ 冰箱管理（Fridge）

1. **查看物品列表**

   - 打开冰箱页面
   - 查看是否显示物品列表

2. **添加物品**

   - 点击右上角 "+" 按钮
   - 填写物品信息：
     - 名称：牛奶
     - 分类：乳制品
     - 图标：🥛
     - 数量：1L
     - 过期日期：选择一个日期
   - 点击"添加"
   - 返回列表查看是否添加成功

3. **搜索物品**

   - 在搜索框输入"牛奶"
   - 查看是否正确过滤

4. **分类过滤**

   - 点击分类标签
   - 查看是否正确过滤

5. **编辑物品**
   - 点击物品卡片
   - 修改信息
   - 点击"更新"
   - 查看是否更新成功

### ✅ 食谱管理（Recipes）

1. **查看食谱列表**

   - 切换到食谱页面
   - 查看食谱列表

2. **添加食谱**

   - 点击右上角 "+" 按钮
   - 填写食谱信息：
     - 名称：番茄炒蛋
     - 标签：快手菜, 家常菜
     - 食材：鸡蛋 2 个\n 番茄 1 个\n 盐适量
     - 步骤：1. 打鸡蛋\n2. 切番茄\n3. 炒制
   - 点击"添加"

3. **搜索食谱**

   - 在搜索框输入食谱名称
   - 查看过滤结果

4. **编辑食谱**
   - 点击食谱卡片
   - 修改信息
   - 点击"更新"

### ✅ AI 聊天（Chat）

1. **发送消息**

   - 切换到聊天页面
   - 输入："你好"
   - 查看 AI 回复

2. **多轮对话**

   - 继续发送："今天吃什么？"
   - 查看 AI 推荐

3. **食谱推荐**
   - 发送："推荐一个简单的菜谱"
   - 查看 AI 回复

### ✅ 设置（Settings）

1. **查看用户信息**

   - 切换到设置页面
   - 查看用户信息

2. **关于信息**
   - 点击"关于 ZenHome"
   - 查看弹窗

## 常见问题

### Q: 页面空白或报错？

A: 检查后端是否正常运行，查看控制台错误信息

### Q: 无法添加物品/食谱？

A: 检查网络请求，确保 API 地址正确（`http://localhost:3000/api`）

### Q: AI 聊天没有回复？

A: 查看后端日志，确认 AI API 配置正确

### Q: 图片上传失败？

A: 确保 Supabase Storage bucket 已创建并配置正确
