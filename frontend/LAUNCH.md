# 微信小程序上线准备指南

## 📋 上线前检查清单

### 一、账号注册与认证

#### 1. 注册小程序账号

- [ ] 访问 [微信公众平台](https://mp.weixin.qq.com)
- [ ] 注册小程序账号（需要未注册过公众号的邮箱）
- [ ] 选择账号类型：
  - **个人**：免费，功能受限，无法开通支付
  - **企业/组织**：需要营业执照，功能完整
  - **政府/媒体**：需要相关资质

#### 2. 小程序认证（可选但推荐）

- [ ] 费用：300 元/年
- [ ] 需要：营业执照、对公账户
- [ ] 好处：
  - 获得更多接口权限
  - 提升用户信任度
  - 可以开通微信支付
  - 搜索排名更靠前

#### 3. 获取 AppID

- [ ] 登录小程序后台
- [ ] 开发 → 开发管理 → 开发设置
- [ ] 复制 AppID
- [ ] 更新 `frontend/project.config.json` 中的 `appid`

---

### 二、开发配置

#### 1. 配置服务器域名（必需）

- [ ] 登录小程序后台
- [ ] 开发 → 开发管理 → 开发设置 → 服务器域名
- [ ] 配置以下域名（必须是 HTTPS）：

**request 合法域名**：

```
https://api.your-domain.com
https://your-project.supabase.co
https://zenmux.ai
```

**uploadFile 合法域名**：

```
https://your-project.supabase.co
```

**downloadFile 合法域名**：

```
https://your-project.supabase.co
```

> ⚠️ **重要**：
>
> - 域名必须备案（中国大陆服务器）
> - 必须支持 HTTPS（SSL 证书）
> - 每月最多修改 5 次

#### 2. 更新前端配置

修改 `frontend/src/config.ts`：

```typescript
export const API_CONFIG = {
  BASE_URL: "https://api.your-domain.com/api",
  TIMEOUT: 10000,
};
```

#### 3. 业务域名配置（如果使用 web-view）

- [ ] 配置业务域名
- [ ] 下载校验文件
- [ ] 上传到服务器根目录

---

### 三、小程序信息完善

#### 1. 基本信息

- [ ] 小程序名称（2-20 个字符）
- [ ] 小程序简介（4-120 个字符）
- [ ] 小程序头像（推荐 144x144px）

#### 2. 服务类目

- [ ] 选择合适的服务类目
- [ ] 建议选择：
  - 生活服务 → 综合生活服务
  - 工具 → 效率工具

> ⚠️ 不同类目需要不同资质，选择前先查看要求

#### 3. 标签设置

- [ ] 添加相关标签（最多 10 个）
- [ ] 示例：厨房、食谱、食材管理、AI 助手

---

### 四、隐私与合规

#### 1. 隐私政策（必需）

- [ ] 编写隐私政策
- [ ] 说明收集的用户信息：
  - 用户昵称、头像（如果使用）
  - 食材和食谱数据
  - 聊天记录（AI 功能）
- [ ] 说明数据用途和保护措施
- [ ] 在小程序中添加隐私政策链接

#### 2. 用户协议

- [ ] 编写用户服务协议
- [ ] 说明服务内容和使用规则

#### 3. 用户信息使用说明

- [ ] 在设置 → 基本设置 → 服务内容声明
- [ ] 填写用户信息使用说明

#### 4. 权限申请

如果使用以下功能，需要在代码中说明用途：

- [ ] 相机权限（拍照识别食材）
- [ ] 相册权限（选择图片）
- [ ] 位置权限（如果需要）

---

### 五、代码准备

#### 1. 版本管理

- [ ] 设置版本号（如 1.0.0）
- [ ] 编写版本说明

#### 2. 代码优化

- [ ] 移除 console.log
- [ ] 压缩图片资源
- [ ] 检查包大小（主包 < 2MB，总包 < 20MB）

#### 3. 错误处理

- [ ] 添加网络错误提示
- [ ] 添加加载状态
- [ ] 添加空状态提示

#### 4. 性能优化

- [ ] 图片懒加载
- [ ] 分包加载（如果需要）
- [ ] 减少请求次数

---

### 六、测试

#### 1. 功能测试

- [ ] 所有页面正常显示
- [ ] 所有功能正常工作
- [ ] 网络异常处理
- [ ] 数据加载和刷新

#### 2. 兼容性测试

- [ ] iOS 真机测试
- [ ] Android 真机测试
- [ ] 不同屏幕尺寸测试

#### 3. 性能测试

- [ ] 启动速度
- [ ] 页面切换流畅度
- [ ] 内存占用

---

### 七、上传代码

#### 1. 在微信开发者工具中

- [ ] 点击"上传"
- [ ] 填写版本号和备注
- [ ] 等待上传完成

#### 2. 在小程序后台

- [ ] 版本管理 → 开发版本
- [ ] 选择刚上传的版本
- [ ] 设为体验版

---

### 八、提交审核

#### 1. 审核前准备

- [ ] 准备测试账号（如果需要登录）
- [ ] 准备演示视频/截图
- [ ] 准备功能说明文档

#### 2. 提交审核

- [ ] 版本管理 → 开发版本 → 提交审核
- [ ] 填写审核信息：
  - 功能页面截图（至少 3 张）
  - 功能描述
  - 测试账号（如果需要）
  - 补充说明

#### 3. 审核注意事项

- [ ] 确保所有功能可用
- [ ] 不要有测试内容
- [ ] 不要有诱导分享
- [ ] 不要有虚假宣传
- [ ] AI 功能需要说明数据来源和处理方式

---

### 九、审核时间

- **一般审核时间**：1-7 个工作日
- **加急审核**：需要认证，2-12 小时（有次数限制）

---

### 十、常见审核不通过原因

1. **服务类目不符**

   - 解决：选择正确的类目

2. **缺少必要资质**

   - 解决：补充相关资质证明

3. **隐私政策不完善**

   - 解决：完善隐私政策，说明数据收集和使用

4. **功能描述不清晰**

   - 解决：详细说明每个功能的用途

5. **测试账号无法使用**

   - 解决：提供可用的测试账号

6. **AI 功能未说明**
   - 解决：说明 AI 模型来源、数据处理方式

---

### 十一、发布上线

#### 1. 审核通过后

- [ ] 版本管理 → 审核版本 → 提交发布
- [ ] 确认发布

#### 2. 发布后

- [ ] 设置体验版（用于内部测试）
- [ ] 监控用户反馈
- [ ] 准备下一版本

## ⚠️ 特别注意

### 1. ZenHome 小程序特殊注意事项

#### AI 功能说明

- [ ] 在审核时说明 AI 功能的用途
- [ ] 说明使用的是第三方 AI 服务（ZenMux）
- [ ] 说明数据处理方式（不存储敏感信息）

#### 图片识别功能

- [ ] 说明图片识别的用途（识别食材）
- [ ] 说明图片处理方式（上传到 Supabase）

#### 数据存储

- [ ] 说明使用 Supabase 存储数据
- [ ] 说明数据安全措施

### 2. 备案要求（如果服务器在中国大陆）

- [ ] 域名需要 ICP 备案
- [ ] 备案时间：15-30 天
- [ ] 备案主体需要与小程序主体一致
