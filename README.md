# ZenHome - 智能厨房管家

一个基于 Taro 的微信小程序，帮助你管理食材库存和食谱。

## 快速开始

```bash
cd frontend
npm install
npm run dev:weapp
```

然后在微信开发者工具中导入 `frontend` 目录。

## 功能特性

- ✅ 食材管理（添加、编辑、删除、搜索、分类过滤）
- ✅ 食谱管理（添加、编辑、删除、搜索）
- ✅ AI 聊天助手（需要后端支持）
- ✅ 图片识别（需要后端支持）
- ✅ 用户设置

## 技术栈

- Taro 4.x
- React 18
- TypeScript
- SCSS
- Webpack 5

## 项目结构

```
zen-home/
├── frontend/          # Taro 微信小程序
└── backend/           # Node.js 后端（待开发）
```
